# Esthétique


## Description de l'esthétique

> « Un duel dramatique et tendu, dans une salle sombre et réverbérante : lent, puis explosif, comme un rituel guerrier et archaïque. »
> — Adam Ben Fradj

| Dimension | 3 mots pour la décrire |
| -- | -- |
| **Émotion** | dramatique, tendu, intimidant |
| **Timbre** | sombre, réverbérant, brillant |
| **Structure** | lent, explosif, progressif |
| **Références** | guerrier, archaïque, mythologique |

Les mots viennent de la banque de mots du cours.

## Intention esthétique

**Faire ressentir l'ivresse du pouvoir et la peur de le perdre.**

- **La lumière isole le roi** : tout est sombre, sauf le trône sous le spot. Le roi est seul au centre de l'attention.
- **Les basses résonnent derrière le trône** : le pouvoir se ressent physiquement, dans le corps.
- **Toute la foule le regarde** : le roi est puissant, mais jamais en sécurité.

## Univers visuel

### Palette

| Couleur | Code | Rôle |
| -- | -- | -- |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#120C0E;border:1px solid #555;vertical-align:middle"></span> Noir velours | `#120C0E` | Le **fond** : la salle, les écrans au repos |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#D9A441;vertical-align:middle"></span> Or | `#D9A441` | Le **pouvoir** : le roi, la couronne, les Fidèles, le spot |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#D9414F;vertical-align:middle"></span> Rouge | `#D9414F` | La **menace** : le challenger, les Rebelles, la chute du roi |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#F2E8D5;vertical-align:middle"></span> Ivoire | `#F2E8D5` | Le **texte** et les visages |

Trois couleurs seulement sur le noir, pour que chaque couleur ait un sens : l'or appartient au roi, le rouge à ceux qui veulent le faire tomber.

### Typographie

- **Titres à l'écran** : une police à empattements (serif), en capitales espacées, pour l'effet de gravure et d'inscription royale (« UN NOUVEAU ROI », « FRAPPEZ ! », « LE ROI EST TOMBÉ »).
- **Informations** (pseudo, score, file d'attente, chronomètre) : une police sans empattements, simple et lisible de loin et sur un petit écran de téléphone.

### Figure et fond

| | Éléments | Traitement |
| -- | -- | -- |
| **Figures** (ce qu'on regarde) | Le roi sous le spot, les duellistes et leurs épées, le pseudo du roi, la couronne, « FRAPPEZ ! », le blason | Or et rouge, contours nets, très contrastés |
| **Fond** (ce qui soutient) | Noir velours, texture de pierre, fumée lente, Galerie qui défile | Sombre, mat, en mouvement très lent |

### Le blason génératif

Chaque blason est unique et construit à partir des données du règne, envoyées par les téléphones :

| Donnée du règne | Élément du blason |
| -- | -- |
| Pseudo | Inscrit sur la banderole sous l'écu ; il sert aussi à tirer au hasard les couleurs et les motifs du fond, donc deux rois n'ont jamais le même blason |
| Victoires de suite | Nombre de pierres sur la couronne et de lauriers autour de l'écu |
| Durée du règne | Taille de la couronne au-dessus de l'écu |
| Geste préféré | Symbole au centre de l'écu : épée, bouclier ou masque |
| Date et heure | Inscription en bas du blason |

Le blason est affiché dans la Galerie et envoyé sur le téléphone de l'ex-roi, qui peut l'enregistrer dans ses photos.

### Lumière

Le spot est un projecteur LED **fixe**, blanc chaud, toujours allumé sur le trône. Toute la dramatisation passe par l'écran et le son : il n'y a pas de lumière programmée à régler.

## Univers sonore

### Fond sonore (ambiance)

- **Trône libre** : nappe grave et réverbérante, comme une grande salle de pierre vide, avec un tambour lointain de temps en temps.
- **Règne** : la même nappe, avec des murmures de foule.

### Sons évènementiels (figures)

| Moment | Son |
| -- | -- |
| Scan du code du trône | Coup de tambour |
| Couronnement | Fanfare de cuivres grave, puis coup de gong |
| Un challenger défie le roi | Coup de tambour et foule qui s'excite |
| Préparation | Battement de cœur qui accélère ; son de verrou quand un joueur valide |
| Fin de la préparation | Son de lame qu'on dégaine |
| Décompte de chaque manche | Trois coups de tambour de plus en plus forts |
| « FRAPPEZ ! » | Grand impact |
| Manche gagnée | Choc d'épées et clameur |
| Égalité | Deux lames qui glissent |
| Décret royal | Son de cor, puis coup de sceau |
| Le roi gagne | Fanfare courte |
| Le roi tombe | Cymbale et cloche |
| Création du blason | Chœur grave |

Les tambours et les impacts passent aussi par le **caisson de basses** placé derrière le trône : le roi les sent dans son dos.

## Méthode et outils

| | Outils | Méthode |
| -- | -- | -- |
| **Images** | Illustrator, Photoshop | Dessin vectoriel des couronnes, icônes de gestes et cadres, exportés en SVG ou PNG pour les pages web |
| **Animations et fond** | p5.js | Fumée et texture de pierre dessinées en temps réel dans la page de l'écran |
| **Blason** | p5.js | Assemblage des calques (écu, couronne, pierres, symbole, banderole) selon les données du règne, puis export en PNG |
| **Interface du téléphone** | HTML, CSS | Gros boutons lisibles d'une main, contraste élevé, testés sur iPhone et Android |
| **Sons** | Reaper, banques de sons libres (Freesound) | Superposition de percussions, cuivres et chœurs ; réverbération longue pour l'effet de grande salle ; export en MP3 pour Howler.js |
