# Esthétique


## Description de l'esthétique

> « Un duel dramatique et tendu, dans une salle sombre et réverbérante : lent, puis explosif, comme un rituel guerrier et archaïque. »
> — Adam Ben Fradj

| Dimension | 3 mots pour la décrire |
| -- | -- |
| **Émotion** | dramatique, tendu, intimidant |
| **Timbre** | sombre, réverbérant, brillant |
| **Structure** | lent, explosif, progressif |
| **Références** | guerrier, archaïque, mythologique |

Les mots viennent de la banque de mots du cours.

## Intention esthétique

**Faire ressentir l'ivresse du pouvoir et la peur de le perdre.**

- **La lumière isole le roi** : tout est sombre, sauf le trône sous le spot. Le roi est seul au centre de l'attention.
- **Les basses font vibrer son siège** : le pouvoir se ressent physiquement, dans le corps.
- **Toute la foule le regarde** : le roi est puissant, mais jamais en sécurité.

## Univers visuel

### Palette

| Couleur | Code | Rôle |
| -- | -- | -- |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#120C0E;border:1px solid #555;vertical-align:middle"></span> Noir velours | `#120C0E` | Le **fond** : la salle, les écrans au repos |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#D9A441;vertical-align:middle"></span> Or | `#D9A441` | Le **pouvoir** : le roi, la couronne, les Fidèles, le spot |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#D9414F;vertical-align:middle"></span> Rouge | `#D9414F` | La **menace** : le challenger, les Rebelles, la chute du roi |
| <span style="display:inline-block;width:1.2em;height:1.2em;background:#F2E8D5;vertical-align:middle"></span> Ivoire | `#F2E8D5` | Le **texte** et les visages |

Trois couleurs seulement sur le noir, pour que chaque couleur ait un sens : l'or appartient au roi, le rouge à ceux qui veulent le faire tomber.

### Typographie

- **Titres à l'écran** : une police à empattements (serif), en capitales espacées, pour l'effet de gravure et d'inscription royale (« UN NOUVEAU ROI », « LE ROI EST TOMBÉ »).
- **Informations** (score, chronomètre, noms des gestes) : une police sans empattements, simple et lisible de loin.

### Figure et fond

| | Éléments | Traitement |
| -- | -- | -- |
| **Figures** (ce qu'on regarde) | Le roi sous le spot, les cartes du duel, la couronne, le portrait, le blason | Or et rouge, contours nets, très contrastés |
| **Fond** (ce qui soutient) | Noir velours, texture de pierre, fumée lente, Galerie qui défile | Sombre, mat, en mouvement très lent |

### Éléments visuels à produire

| Élément | Où | Description |
| -- | -- | -- |
| **Cartes de gestes** | Écran principal | 3 faces (Attaque : épée, Parade : bouclier, Feinte : masque) et 1 dos commun avec un losange doré |
| **Couronne** | Écran principal | Couronne dorée avec des emplacements de pierres rouges (une pierre par victoire) |
| **Cadre de portrait** | Écran principal | Cadre doré pour la photo du roi ; version fissurée pour la chute |
| **Jauge de la Cour** | Bas de l'écran | Flammes dorées (Fidèles) contre flammes rouges (Rebelles) |
| **Bouclier de Faveur** | Écran principal | Petit bouclier doré qui apparaît du côté du camp majoritaire |
| **Parchemin de décret** | Écran principal | Parchemin qui se déroule, avec un sceau rouge |
| **Roi Fantôme** | Écran principal | Silhouette couronnée, translucide, faite de fumée |
| **Textes d'annonce** | Écran principal | « UN NOUVEAU ROI », « LE ROI RÈGNE », « LE ROI EST TOMBÉ », « LÈVE-TOI », « Qui osera ? » |
| **Fond animé** | Les deux écrans | Texture de pierre sombre avec fumée lente |
| **Blason** | Galerie et ticket | Généré pour chaque roi (voir ci-dessous) |

### Le blason génératif

Chaque blason est unique et construit à partir des données du règne :

| Donnée du règne | Élément du blason |
| -- | -- |
| Photo du roi | Portrait stylisé au centre (contraste élevé, en or sur fond rouge) |
| Durée du règne | Taille de la couronne au-dessus de l'écu |
| Nombre de victoires | Nombre de pierres sur la couronne et de lauriers autour |
| Geste préféré | Symbole sous le portrait : épée, bouclier ou masque |
| Date et heure | Inscription en bas du blason |

Sur le ticket imprimé, le blason est converti en noir et blanc à fort contraste pour l'imprimante thermique.

### Lumière

| Moment | Spot DMX |
| -- | -- |
| Trône vide | Blanc chaud à 30 %, respiration lente |
| Couronnement | Blanc chaud à 100 % |
| Règne | Or à 80 % |
| Choix secret | Or à 60 % |
| Révélation lente | Tremblement (variation rapide d'intensité), puis flash à l'impact |
| Le roi est tombé | Rouge clignotant |

## Univers sonore

### Fond sonore (ambiance)

- **Salle vide** : nappe grave et réverbérante, comme une grande salle de pierre, avec un tambour lointain de temps en temps.
- **Règne** : la même nappe, avec des murmures de foule dont le volume suit le nombre de personnes sur les tapis.

### Sons évènementiels (figures)

| Moment | Son |
| -- | -- |
| Quelqu'un s'assoit sur le trône | Tambour qui accélère, puis fanfare de cuivres grave |
| Photo du roi | Coup de gong |
| Un visiteur change de camp | Murmure « Ooooh » de trahison |
| Un challenger monte sur le piédestal | Coup de tambour et foule qui s'excite |
| Choix secret | Battement de cœur qui accélère ; son de verrou quand un joueur a choisi |
| Révélation lente | Montée de cordes et de percussions (3 s), silence de 0,5 s, puis impact |
| Égalité | Choc d'épées |
| Faveur de la Cour | Choc métallique sur un bouclier |
| Décret royal | Son de cor, puis coup de sceau |
| Le roi gagne | Fanfare courte |
| Le roi tombe | Cymbale et cloche |
| Création du blason | Chœur grave |

Les sons graves (fanfare, impact, gong) passent aussi dans le **transducteur tactile** sous le trône : le roi les sent dans son corps.

## Méthode et outils

| | Outils | Méthode |
| -- | -- | -- |
| **Images** | Illustrator, Photoshop | Dessin vectoriel des cartes, couronnes et cadres, exportés en PNG transparents pour Unity |
| **Animations et fond** | TouchDesigner, Unity (particules, shaders) | Fumée et texture de pierre en temps réel ; animations des cartes dans Unity |
| **Blason** | Unity (C#) | Assemblage des calques (écu, couronne, pierres, symbole, portrait) selon les données du règne |
| **Sons** | Reaper, banques de sons libres (Freesound) | Superposition de percussions, cuivres et chœurs ; réverbération longue pour l'effet de grande salle ; export en WAV pour Unity |
